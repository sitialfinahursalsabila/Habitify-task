Habitify Task 📋✨

A modern habit and task management web application built with HTML, CSS, and JavaScript.
Habitify Task helps you organize daily tasks, build productive habits, and visualize progress with interactive charts and analytics.

🌟 Features
📊 Productivity Analytics

Visualize your performance with powerful charts:

Daily Progress Chart – Shows task completion percentage

Weekly Activity Chart – Track your productivity every week

Monthly Performance – Analyze long-term progress

Streak Tracking – Monitor consistency and habit streaks

📝 Task & Habit Management

Habitify Task lets you manage both tasks and habits in one place.

Features include:

✅ Add new tasks or habits

✏️ Edit existing tasks

🗑️ Delete tasks

📂 Organize tasks by category

🎯 Set daily or weekly targets

📅 Custom schedule for specific days

Categories include:

🏃 Health

📈 Productivity

📚 Learning

🧘 Mindfulness

👥 Social

🎨 Creativity

📝 Others

📅 Calendar Productivity View

The Calendar tab gives you a clear overview of your productivity.

Features:

Monthly calendar display

Daily progress indicators

Navigate between months

Visual habit completion history

📱 Modern User Interface

Habitify Task uses a clean and modern UI.

Highlights:

Responsive design (desktop, tablet, mobile)

Beautiful gradient layout

Smooth animations

Interactive dashboard

Minimal and productivity-focused design

💾 Data Storage & Backup

Habitify Task stores data locally using browser localStorage.

Features:

💾 Automatic local saving

📤 Export tasks and habits as JSON

📥 Import backup files

🔄 Transfer data between devices

Your data remains private and stored only on your device.

🚀 Getting Started
Option 1 — Open Directly

Download project files:

index.html

styles.css

script.js

Open index.html in your browser.

Option 2 — Use Local Server (Recommended)
Python
python -m http.server 8080
Node.js
npx serve -p 8080

Open:

http://localhost:8080
📋 How to Use
Add New Task / Habit

Click Add New Task

Fill in details:

Task Name

Description

Category

Frequency

Target (optional)

Click Save Task

Track Daily Progress

Go to Dashboard

Click the check icon next to a task

The chart will update automatically

View Analytics

Navigate to the Analytics tab to see:

Monthly productivity charts

Habit distribution

Streak statistics

Overall completion rate

Use the Calendar

Open Calendar tab

See daily completion progress

Navigate months to check productivity history

🎨 Customization

You can easily customize the application.

Change Theme Colors

Edit styles.css:

:root{
--primary-color:#667eea;
--secondary-color:#764ba2;
--success-color:#4CAF50;
--danger-color:#ff5252;
}

}
